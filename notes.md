* tutorials
  * for learning
  * teach - enjoyable - wants to come back
  * learn by doing
  * practical knowledge
  * inspire confidence
  * easy to follow
  * immediate sense of achievement
  * concrete first (then general later)
  * don't explain anything they don't need to know right now
  * not a time to provide options .... keep it very simple
  * not a time to proivde information - instead should focus on actions
  * think of "teaching children" (or absent teacher)
  * think documenting a real live tutorial
* how to guides (think checklist like for pilots)
  * recipie for a specific task
  * goal oriented
  * addresses a specific question
  * answeres a question that a beginer might not even know to ask (beginer uses turtorial).
  * resonable starting and end points - but can start in the middle
  * can assume resonable background
  * again avoid distractions
  * don't explain - just provide solution
  * don't need to cover every single detail
* reference
  * technical description of functions/data structures
  * information oriented
  * can include examples
  * should be dry factual
  * mirror structure of code
  * consistent formating
  * accurate and up to date
* explanation (key topics, discussions)
  * illuniate or clarify a topic
  * understanding of concepts
  * historical
  * background
  * why things are they way they are
  * make connectiosn
  * highlight alternatives


Hard to keep these things separate
